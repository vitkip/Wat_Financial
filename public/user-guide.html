ໂໝດ 02

ລາຍການທຸລະກຳ

URL: /Wat_Financial/transactions

ຈັດການລາຍການເງິນທຸກລາຍການ — ທັງລາຍຮັບ ແລ ລາຍຈ່າຍ. ຮອງຮັບການຄົ້ນຫາ, ກັ່ນຕອງ, ແລ ການ pagination.

ການເພີ່ມລາຍການໃໝ່

  1. 1

    ກົດປຸ່ມ "ເພີ່ມລາຍການ"

    ປຸ່ມສີດຳ ຢູ່ດ້ານຂວາເທິງ. Modal form ຈະເປີດຂຶ້ນ.

  2. 2

    ເລືອກປະເພດ

    ລາຍຮັບ ສຳລັບເງິນທີ່ຮັບ (ເງິນເດືອນ, bonus, ລາຍໄດ້ຈາກ freelance)
    ລາຍຈ່າຍ ສຳລັບເງິນທີ່ຈ່າຍ (ອາຫານ, ຄ່າເຊົ່າ, ໄຟຟ້າ)

  3. 3

    ກອກຂໍ້ມູນ

    ຊ່ອງທີ່ມີ * ບັງຄັບ. ໝວດໝູ່ ແລ ໝາຍເຫດ ເປັນທາງເລືອກ.

  4. 4

    ກົດ "ບັນທຶກ"

    ລາຍການຈະຖືກບັນທຶກ ແລ ໜ້າ reload ພ້ອມແຈ້ງເຕືອນ "ເພີ່ມລາຍການສຳເລັດ".

ການຄົ້ນຫາ ແລ ກັ່ນຕອງ

ການແກ້ໄຂ ແລ ລຶບລາຍການ

ແກ້ໄຂ (Edit)

ກົດ icon ດິນສໍ ✎ ທາງຂວາຂອງລາຍການ → Modal ຈະໂຫຼດຂໍ້ມູນເດີມ → ແກ້ໄຂ → "ອັບເດດ".

ລຶບ (Delete)

ກົດ icon ຖັງຂີ້ເຫຍື້ອ 🗑 → ກ່ອງຢືນຢັນຈະຂຶ້ນ → ກົດ "ຢືນຢັນ" ເພື່ອລຶບຖາວອນ.

Pagination

ລາຍການຖືກແບ່ງໜ້າ (ຄ່າ default: 15 ລາຍການ/ໜ້າ). ຕັ້ງຄ່າໄດ້ໃນ Settings.

ການຕັ້ງງົບປະມານ

  1. 1

    ເລືອກເດືອນ

    ໃຊ້ month picker ທາງຂວາເທິງ ເພື່ອເລືອກເດືອນທີ່ຕ້ອງການຕັ້ງງົບ. ຄ່າ default ຄືເດືອນປັດຈຸບັນ.

  2. 2

    ກົດ "ຕັ້ງງົບໃໝ່"

    ເລືອກ ໝວດໝູ່ ແລ ໃສ່ ຈຳນວນງົບ ທີ່ຕ້ອງການ. ໝວດໝູ່ 1 ອັນ ຕໍ່ 1 ເດືອນ ມີໄດ້ 1 ງົບ.

  3. 3

    ຕິດຕາມ Progress

    ລະບົບຄຳນວນຍອດ "ໃຊ້ຈ່າຍ" ຈາກ transactions ໝວດໝູ່ນັ້ນ ໃນເດືອນນັ້ນໂດຍອັດຕະໂນມັດ.

ງົບເກີນ: ຖ້າ progress bar ສະແດງສີແດງ ໝາຍຄວາມວ່າໃຊ້ຈ່າຍເກີນງົບທີ່ຕັ້ງໄວ້ ໃນໝວດໝູ່ນັ້ນ.

ສ່ວນຄວາມໝາຍ
ງົບທີ່ຕັ້ງຈຳນວນງົບທີ່ທ່ານກຳນົດໄວ້
ໃຊ້ຈ່າຍໄປລວມ expense ໝວດໝູ່ນັ້ນ ໃນເດືອນທີ່ເລືອກ
ຍັງເຫຼືອງົບຕັ້ງ – ໃຊ້ຈ່າຍ (ສີຂຽວ = ຍັງໃນງົບ)
ເກີນງົບໃຊ້ຈ່າຍ – ງົບຕັ້ງ (ສີແດງ = ຕ້ອງລະວັງ)

ໂໝດ 04

ເປົ້າໝາຍການເງິນ

URL: /Wat_Financial/goals

ສ້າງເປົ້າໝາຍການເງິນ ເຊັ່ນ: ຊື້ລົດ, ທ່ອງທ່ຽວ, ກອງທຶນສຸກເສີນ ແລ ຕິດຕາມຄວາມຄືບໜ້າ.

ການສ້າງເປົ້າໝາຍໃໝ່

ການເພີ່ມເງິນເຂົ້າເປົ້າໝາຍ

  1. 1

    ຊອກຫາ Card ເປົ້າໝາຍ

    ແຕ່ລະ card ຈະສະແດງ progress bar, ຈຳນວນທີ່ສະສົມ, ແລ ຈຳນວນທີ່ຍັງຂາດ.

  2. 2

    ກົດ "ເພີ່ມເງິນ"

    ໃສ່ຈຳນວນທີ່ຕ້ອງການ deposit ເຂົ້າເປົ້າໝາຍ. ລະບົບຈະ update progress bar ທັນທີ.

  3. 3

    ເປົ້າໝາຍສຳເລັດ

    ຕອນ current_amount ຮອດ target_amount ລະບົບຈະໝາຍ ✅ Completed ໃຫ້ອັດຕະໂນມັດ.

ຂໍ້ດີ: ເປົ້າໝາຍທີ່ສຳເລັດຈະຖືກແຍກສະແດງ ເພື່ອໃຫ້ເຫັນຜົນສຳເລັດທີ່ຜ່ານມາ ແລ ສ້າງ motivation.

ໂໝດ 05

ລາຍງານ

URL: /Wat_Financial/reports

ລາຍງານທາງການເງິນ ລາຍປີ — ສະຫຼຸບ ລາຍຮັບ, ລາຍຈ່າຍ ແລ ຍອດສຸດທິ ທຸກ 12 ເດືອນ ພ້ອມ chart ແລ ໝວດໝູ່ຍອດນິຍົມ.

ສະຫຼຸບລາຍປີ

KPI 3 ຕົວ: ລວມລາຍຮັບ, ລວມລາຍຈ່າຍ, ຍອດສຸດທິ ທັງປີ. ໃຊ້ selector ດ້ານຂວາເພື່ອເບິ່ງປີຕ່າງໆ.

ຕາຕະລາງ 12 ເດືອນ

ແຕ່ລະເດືອນສະແດງ: ລາຍຮັບ, ລາຍຈ່າຍ, ຍອດ net ສີຂຽວ (+ ໄດ້) ຫຼື ສີແດງ (– ຂາດ).

Top Categories

ສະແດງ 5 ໝວດໝູ່ທີ່ໃຊ້ຈ່າຍສູງສຸດໃນປີ ພ້ອມ bar chart ແລ ຈຳນວນ % ຂອງທັງໝົດ.

ເລືອກປີ

ກົດ ← → ທີ່ ➩ year selector ເພື່ອເດີນທາງລະຫວ່າງປີ. ລະບົບໂຫຼດຂໍ້ມູນໃໝ່ທັນທີ.

Export: ໃນໜ້ານີ້ມີປຸ່ມ "Export CSV" ແລ "Export PDF" ຢູ່ດ້ານຂວາ ສຳລັບດາວໂຫຼດລາຍງານ. ລາຍລະອຽດ → ໂໝດ Export.

ຟັງຊັ້ນທີ່ໃຊ້ໄດ້

ສ້າງລາຍການ (Generate)

ກົດ "ສ້າງ" ໃນ row ທີ່ຕ້ອງການ → ລາຍການທຸລະກຳຈະຖືກ insert ທັນທີ ພ້ອມ update "ຄັ້ງຕໍ່ໄປ" ໂດຍອັດຕະໂນມັດ.

ເປີດ/ປິດ (Toggle)

ກົດ switch ເພື່ອ enable/disable. ລາຍການທີ່ປິດ inactive ຈະ generate ບໍ່ໄດ້.

ລຶບ (Delete)

ລຶບ template ລາຍການຊ້ຳ. ລາຍການທຸລະກຳທີ່ generate ໄປແລ້ວ ຈະບໍ່ຖືກລຶບ.

ໝາຍເຫດ: ລະບົບບໍ່ສ້າງລາຍການ Auto ຂຶ້ນເອງ. ຕ້ອງກົດ "ສ້າງ" ດ້ວຍຕົນເອງ ທຸກຄັ້ງທີ່ຕ້ອງການ. ຖ້າຕ້ອງການ Auto ຕ້ອງຕັ້ງ cron job ໃນ server.

ໂໝດ 07

Export ຂໍ້ມູນ

URL: /Wat_Financial/export/transactions · /Wat_Financial/export/report

ດາວໂຫຼດຂໍ້ມູນການເງິນໃນຮູບແບບ CSV (ສຳລັບ Excel) ຫຼື PDF (ສຳລັບພິມ) ໄດ້ 2 ແບບ.

CSV / Excel

ດາວໂຫຼດ .csv ທີ່ມີ BOM encoding ສຳລັບ Excel ໃຫ້ຮຮຕົວໜັງສືລາວຖືກຕ້ອງ.

  • ລາຍລະອຽດທຸກ transaction
  • ໝວດໝູ່, ວັນທີ, ໝາຍເຫດ
  • Summary rows (ລວມ income/expense)

PDF (Print View)

HTML print view ທີ່ browser ຈະ render ເປັນ PDF. ໃຊ້ Ctrl+P ຫຼື ⌘+P ໃນ browser ເພື່ອ save PDF.

  • Layout ສວຍງາມ ສຳລັບພິມ
  • Header, footer, ຊື່ Report
  • ສີ income/expense ຮັກສາໄວ້

ປະເພດ Export

ປະເພດທາງເລືອກໃຊ້ງານ
Transactions Export ຮອງຮັບ filter ດຽວກັນກັບໜ້າ Transactions (ຄົ້ນຫາ, ວັນທີ, ໝວດ...) ໜ້າ Transactions → ປຸ່ມ "Export"
Monthly Report Export ລາຍການທຸກຕົວ ຂອງເດືອນໃດໜຶ່ງ ໜ້າ Reports → "Export CSV/PDF" → ເລືອກເດືອນ
Yearly Report ສະຫຼຸບ 12 ເດືອນ + ລາຍການທຸກຕົວ ໃນ CSV ດຽວ ໜ້າ Reports → "Export CSV/PDF" → ບໍ່ລະບຸເດືອນ

ຊື່ໄຟລ໌: CSV ຈະຕັ້ງຊື່ດ້ວຍ timestamp ໂດຍອັດຕະໂນມັດ ເຊັ່ນ transactions_20260415_143022.csv ຫຼື report_2026_20260415.csv.
